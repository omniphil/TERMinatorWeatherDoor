# TERMinator Weather

A weather door for BBSes. Callers with TERMinator get a full graphical forecast through TRACE: an animated sky that
follows the real conditions and the real sun and moon, an hourly chart, a 7-day strip and a location picker, all
driven by mouse or keyboard. Everyone else gets a 24-bit ANSI screen with the same forecast and an animated weather
icon. The ANSI screen is laid out in 79x24, so nothing ever lands in the last column or row and makes a terminal scroll.

Forecasts come from [Open-Meteo](https://open-meteo.com) (free, no API key, CC BY 4.0), fetched and cached on the BBS.
Each caller's place, units and display choice are remembered.

## How it works

| Piece | Where | What |
|---|---|---|
| `door/weatherdoor` | the BBS | Start page (TRACE or ANSI, like the DOOM door), place search, forecast fetch + cache, the ANSI view, and the pipe to the module |
| `module/weather.wasm` | the caller's TERMinator | Draws everything in TRACE. Renders at 640x480 or 1280x960, whichever fits the window, so text is always sharp |

The module uses the mouse, so it needs TERMinator 1.1.3 or later (every desktop client has it). WASM imports are
static, so on an older TERMinator it wouldn't start at all: the door only offers TRACE when the terminal reports
`mouse=1`, and otherwise tells the caller to update and defaults to ANSI.

The door sends the forecast to the module as small metric structs (`module/src/protocol.h`); the module converts units
itself, so switching F/C never refetches. `module/src/wxcommon.h` holds the condition names both views share.

- **Network:** HTTP goes through the `curl` command, run with fork/exec (a caller's search text never reaches a shell).
- **Cache:** forecasts are cached in `door/cache/` for `cache_minutes`, keyed to about 1 km, so callers in one town share a fetch. A failed fetch falls back to an older cached forecast.
- **Place search:** Open-Meteo's geocoder handles names, "City, ST" and postcodes; the door also ranks results by the part after the comma ("Springfield, IL").

## Install

```
make -C module            # needs wasi-sdk 34+ in ~/tools (WASI_SDK=... to override)
make -C door install      # copies weather.wasm beside the door, makes weather.ini, saves/, cache/
```

Copy the whole `door/` folder to the BBS and point a door entry at `weatherdoor <dir containing door32.sys>`.
Everything resolves beside the binary, never the cwd. Needed at runtime: `weatherdoor`, `weather.wasm`,
`weather.ini`, and `curl` on the PATH. `saves/` and `cache/` are created as needed.

To build on the BBS itself: `make -C door bundle` first (copies the two shared headers into `door/native/`), then
`make clean && make` works in `door/` with nothing beside it.

Set the board's own town in `weather.ini` (see `weather.ini.example`): it's what callers see until they pick a place.

## Keys

| | TRACE | ANSI |
|---|---|---|
| Hours | hover the chart, wheel, Left/Right | Left/Right (3 hours) |
| Days | click a card, Up/Down, 1-7, Tab | Up/Down, 1-7, Tab |
| Location | click the place, L | L |
| Units | click the F/C switch, U (or F / C) | U (or F / C) |
| Refresh | the refresh button, R | R |
| Quit | the X, Esc, Q | Esc, Q |

A first-time caller is asked for their location straight away; Esc keeps the board default.

## Testing

```
python3 door/test_door.py            # fake TERMinator on a pty: base64 transport
python3 door/test_door.py --bin      # binary frames
python3 door/test_door.py --nomouse  # pre-1.1.3 TERMinator: TRACE refused, "update" shown
python3 tools/ansi_shot.py out.png 2 @WAIT u   # the ANSI view, rendered to a PNG
```

`test_door.py` talks to the real Open-Meteo (needs the network). It runs the door from an unrelated directory, checks the
module hash, the forecast packets, a search, a pick and a unit change, and that prefs land beside the binary.

`tools/render_preview.c` compiles the module natively with stubbed host calls and writes a frame to a `.ppm`:

```
gcc -O2 -Wno-attributes -I module/src -I door tools/render_preview.c door/door.c -lm -o preview
./preview --hour 19 --code 2 --day 3 out.ppm     # sunset, partly cloudy, Thursday selected
```

Options: `--scale 1|2`, `--code N` (WMO code), `--hour H`, `--hover I`, `--day D`, `--picker`, `--loading`, `--metric`.

## Fonts

`module/src/fonts.h` is generated by `tools/make_fonts.py` from Ubuntu (Ubuntu Font Licence 1.0, which allows
embedding) at 1x and 2x. Regenerate with `make -C module fonts`.
